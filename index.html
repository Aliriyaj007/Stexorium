🛠️ Offline Setup Guide

If you are completely offline, the QR Scanner and Markdown features won't work because they can't reach the CDN.

To fix this:

  1. Download these 3 files and save them in the same folder as this HTML file:
  2. qrcode.min.js
  3. jsQR.min.js
  4. marked.min.js
  5. Edit this HTML file: Change the src="https://..." lines at the top to src="./filename.js".
<script src="./qrcode.min.js"></script> <script src="./jsQR.min.js"></script> <script src="./marked.min.js"></script>
